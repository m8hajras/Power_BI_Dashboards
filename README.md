## Introduction

This is a test dashboard for the **Power BI** course video on **Luke Barousse** youtube channel. I'm uploading it to **Github** to prove having knowledge in making and sharing dashboards.

## Skills Showcased

- **Charts and Visualizations:** Using different charts to showcase data within the dashboard, as well as navigation tools such as *Slicers*,*Bookmarks*, and *Drill Through*. 
- **Measures:** Creating different measures to calculate certain datasets and aspects not included in the table.
- **Design:** Tailoring the dashboard to be appealing to viewers using comfortable colors and shapes that lead viewers to key features and data.
